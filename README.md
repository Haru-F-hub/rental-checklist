# 租房检查清单

一个无需安装、双击即可使用的租房看房检查网页。看房时逐项打勾，最后自动计算评分，帮你判断这套房子值不值得租。

## 功能

- **44 个检查项，6 大类**：门窗与安全、水电燃气、家电与家具、墙面漏水与异味、采光噪音与周边、合同与费用。
- **每项三种状态**：`✓ 合格`、`✗ 有问题`、空白（未检查）。
- **权重评分**：每项权重 2～5 分，权重 5 为关键项。得分 = 合格项权重 ÷ 计入项权重总和 × 100。
- **未检查项提示**：点击「计算得分」时，会列出所有未检查项，由你自己决定哪些计入评分、哪些跳过。
- **分类得分与问题清单**：结果页展示总分、等级、各分类得分，以及按严重程度排序的不合格项。
- **自动保存**：勾选内容保存在浏览器本地（localStorage），刷新、关闭重开都不会丢。
- 支持手机浏览、暗色模式，无任何第三方依赖。

## 评分规则

| 等级 | 分数 | 含义 |
| --- | --- | --- |
| 优秀 | 90～100 | 房屋状况良好，可以放心签约 |
| 良好 | 75～89 | 整体不错，建议先让房东整改扣分项 |
| 一般 | 60～74 | 有明显短板，建议压价或要求维修 |
| 较差 | 40～59 | 问题较多，建议再看看别的房子 |
| 很差 | 0～39 | 不建议租，隐患较多 |

> 权重 5 的关键项（如门锁、漏电、燃气泄漏、一氧化碳、押金条款）不合格时，结果页会单独警告。

## 使用提醒

- 看房时对全屋、家具家电、水电燃气表拍照录像。
- 已有的破损、污渍当场发给房东确认。
- 维修责任、费用承担、押金退还条件一定要写进合同。
- 自动保存只存在当前浏览器里；换设备或清理浏览器缓存后会丢失。
